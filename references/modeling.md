# 背景与模型资产契约

1. 外观图回答“想长什么样”；高度图回答“正面表面在哪里”；GLB 才包含实际顶点。三者不是同一件事。
2. 单图无法准确恢复遮挡、倒扣、头发背面。图像生成或深度估计只给参考；检查脸、肩、手臂、剑等主形体，按主体重新校正大体积。不要照搬原案例骑士的高斯参数。
3. 本技能 scripts/build_height_relief.py 是可重复的高度场起点，不是自动人物雕刻器。输入须先通过视觉检查。它使用 Blender 内置 Python/NumPy，无须另外安装 Python 包。

```powershell
& '<Blender可执行文件>' --background --factory-startup --python '<技能目录>/scripts/build_height_relief.py' -- --height '<高度图.png>' --out '<新模型目录>'
```

输出 relief.blend、relief.glb、height.png、front.png、oblique.png、geometry.json。默认160列，行数按输入比例；高频图案可增加列数，但需验证移动端性能。输出目录必须不存在。

## 导出规范

宽2单位，模型高度=2×图像高宽比，Blender XY 为正面，Z=线性高度×0.26；应用全部对象变换。GLB 导出转到 Y-up，网页映射 X、-Z 到平面，Y/0.26 到深度。GLB 只含需要的网格，未压缩、嵌入 BIN、三角形，无骨骼/动画/外部 buffer。当前窄加载器拒绝节点变换，不能处理任意场景。

将 profile.background 指向与高度图同构图的外观/备用图，profile.height 指向输出 height.png，profile.model 指向 relief.glb。front.png 主要用于检查材质，是否适合备用图须检查相机裁切；不要把带边距的渲染当作严格对齐纹理。若使用任意第三方 GLB，换成熟 glTF 加载器，并重建纹理、坐标与深度契约。

高度源经8位浏览器图像上传可能损失精度；16位文件不意味着GPU采样仍有16位。高精度诉求应改为浮点纹理或直接使用模型法线。当前网页动态法线来自高度梯度，没有读取导出的法线图。

## 必须检查

在纯石膏材质、无原图贴图时查看正面/斜面；检查面朝向、单位、有限坐标、UV、裁切。高度场脚本没有自动做背板封闭，正面网站可用，打印或环绕观看需另做拓扑。网页灯光与离线渲染不同，要分别验收。网页高对比不能补救错误几何。
