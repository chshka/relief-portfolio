# 组件与两种运行路线

没有前端框架运行依赖。assets/starter是早期单背景；assets/gallery-starter是当前长廊，禁止交叉覆盖shader与布局代码。

| 文件 | 负责什么 | 常见修改 |
|---|---|---|
| index.html | 可读DOM、章节、邮箱、图案蒙版 | 资料和章节 |
| style.css | 布局、字体、层级、响应式 | 桌面错落定位；手机上下排版 |
| app.js | 导航、显现观察、暂停；gallery滚轮横移 | 阻止吸附；维护真实滚动坐标 |
| gallery-assets.js | gallery素材顺序、宽高比、模型路径 | 增删或重排panels后重新生成或定向编辑 |
| relief-background.js | Web Component、输入、生命周期、资源与绘制 | gallery可见绘制、预载、回收 |
| relief-model.js | 窄GLB读取、顶点坐标转换 | 只接受契约内模型 |
| relief-surface.js | 顶点着色器、高度网格备用、随机自动路径 | 隆起幅度和投影微位移 |
| relief-flow.js | 192²双缓冲流场、输运、扩散、衰减、材质 | 背景显现源与手动源独立 |
| relief-text.js | DOM字形栅格化、20次方向采样 | 仅使用手动流场；选择与暂停恢复DOM |
| loading-screen.js | 阶段进度、顺时针填色、失败退出 | 不是下载字节百分比 |
| server.mjs | 本地静态服务，PORT可配置 | 与正式托管不同 |

## single 早期机制

影像与高度图建立浮雕；白底/阴影与完整受光材质按显现值混合。顶点也有起伏，但视觉主要是遮罩显现。桌面以文档高度映射背景、与文字同速；手机保留原来的视口裁切。它用于教程入门，不代表当前长廊效果。

## gallery 当前机制

同一画布只绘制视口中的面板；前后邻近预载，远处释放GPU模型和纹理。首屏模型完成即可结束加载页。每帧共享背景流场，文字另用手动流场，自动和手动可同时运行。

顶点高度 z = 原始高度 × mix(0.055,1,smoothstep(0.045,0.46,流场alpha))。片元使用相同增长系数计算邻近高度、法线和局部遮蔽，再计算同一白色材质的漫反射。没有白色遮罩与照片之间的混合。关闭动画时增长系数=1，展示完整静态浮雕。

- 自动：随机边到边三次曲线，5.5–9秒一段，间隔1–3秒。
- 手动：pointer/touch被动监听，位置与速度驱动局部扰动。
- 膨起作用核 exp(-r²/0.0266667)：当前半径是上一宽范围版的2/3。想按比例k改半径，分母乘k²；不直接乘k。
- 注入0.11、增长阈值0.045→0.46。提高注入会更快隆起；提高阈值会更慢达到完全高度。
- 流场是程序卷曲与双缓冲输运近似，不是完整Navier–Stokes流体。
- 接触阴影由邻近高度取样近似，没有完整场景阴影贴图、光线追踪或真实体积雾。
- 白色材质使用中性亮度、柔和补光与细微颗粒，不带彩色金属高光。细节上限取决于模型和高度图。

性能：背景和文字两个WebGL上下文，不是每幅一个。文字GPU有CPU读回成本，gallery手动扰动停止约2.5秒后恢复DOM文字。清晰度、网格数量和像素比须在实际设备权衡。
